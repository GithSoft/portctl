## Core Pillars

<CardGrid>
  <Card title="⚡ Sub-Millisecond Speed" icon="rocket">
    Written in pure Rust with zero daemon overhead and zero runtime dependencies. Queries complete in **< 3ms** with sub-megabyte memory footprint.
  </Card>

  <Card title="🛡️ POSIX Advisory Locking" icon="seti:lock">
    Atomic writes and `fd-lock` file advisory locks eliminate race conditions across concurrent terminal sessions. Strict `0600` permissions and built-in protection against exposing sensitive ports (`22`, `5432`, `6379`).
  </Card>

  <Card title="🧠 Polyglot Auto-Detection" icon="laptop">
    Automatically identifies project names from `package.json`, `Cargo.toml`, `pyproject.toml`, `go.mod`, `pom.xml`, `composer.json`, or Git remotes without manual naming.
  </Card>

  <Card title="🌐 Automated Edge Ingress" icon="seti:cloudflare">
    1-click Cloudflare Tunnel automation. Validates ingress syntax, configures DNS routing, and updates daemons with zero YAML wrangling.
  </Card>
</CardGrid>

## Performance Benchmarks

Execution latency comparison for resolving and probing local socket allocations:

| Tool | Runtime | Architecture | Average Latency | Daemon RAM |
| :--- | :--- | :--- | :--- | :--- |
| **`portctl` (Rust)** | **Native Binary** | **Zero-Daemon** | **< 2.4 ms** | **0 MB** |
| Custom Bash / `lsof` Script | Shell `/bin/bash` | Child Processes | ~18.5 ms | 0 MB |
| Legacy Node.js CLI | V8 / Node.js | JIT Runtime | ~165 ms | ~45 MB |
| Desktop Container Apps | Electron / Hypervisor | Background Daemon | > 500 ms | > 2,000 MB |
